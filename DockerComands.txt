docker container run -t ubuntu top

Cria um container baseado no Ubuntu e executa o monitor de processos (top) dentro dele.

docker container run --detach --publish 8080:80 --name nginx nginx

Cria e executa um servidor web Nginx em segundo plano(--detach), acessível na porta 8080 do teu computador.

sudo docker stop $(sudo docker ps -q)

Para todos os containers que estão atualmente em execução.

sudo docker ps -a

Mostra todos os containers que existem na máquina, independentemente de estarem ativos ou não.

docker container run --detach --publish 8081:27017 --name mongo mongo:3.4

Cria e executa um servidor MongoDB em segundo plano, acessível através da porta 8081 da máquina local.

docker container ls → Lista todos os containers em execução no momento.

touch Dockerfile
Cria o ficheiro onde vamos escrever as instruções para construir uma imagem Docker personalizada.

FROM python:3.6.1-alpine
RUN pip install --upgrade pip
RUN pip install flask
CMD ["python","app.py"]
COPY app.py /app.py

Cria uma imagem Docker capaz de executar uma aplicação Flask escrita em Python.

docker image build -t python-newprogram .

cria uma nova imagem Docker a partir de um Dockerfile, e a opção -t permite definir um nome para essa imagem.

O ponto (.) no final do comando docker build indica que o diretório atual será utilizado como contexto de construção, permitindo ao Docker acessar o Dockerfile e os demais ficheiros necessários para criar a imagem.

docker run -p 5001:5000 -d python-newprogram

Executa uma aplicação dentro de um container e torna-a acessível na porta 5001 da máquina local.

docker image ls

Mostra as imagens que já foram baixadas ou criadas no teu sistema.

docker image rm [id do image]

emove uma imagem Docker do sistema local, desde que ela não esteja em uso por containers ativos.

docker container logs [container id] 

O comando docker container logs é utilizado para visualizar os registos (logs) de saída de um container específico.

docker swarm init --advertise-addr eth0

O comando docker swarm init inicializa um cluster Docker Swarm e transforma a máquina atual em nó gestor (manager). A opção --advertise-addr define o endereço de rede que será anunciado para permitir que outros nós se conectem ao cluster.

docker node ls

O comando docker node ls lista todos os nós de um cluster Docker Swarm, mostrando informações detalhadas sobre cada nó, incluindo status, função e disponibilidade.

docker service create --detach=true --name nginx1 --publish 80:80  --mount source=/etc/hostname,target=/usr/share/nginx/html/index.html,type=bind,ro nginx:1.12 pgqdxr41dpy8qwkn6qm7vke0q

O comando cria um serviço Docker chamado nginx1 no Swarm, baseado na imagem nginx:1.12, executa em segundo plano, publica a porta 80 e monta o ficheiro /etc/hostname como página inicial em modo somente leitura.

docker service ls

O comando docker service ls lista todos os serviços do cluster Docker Swarm, mostrando o nome, modo de execução, número de réplicas, imagem utilizada e portas publicadas de cada serviço.

docker service ps nginx1

O comando docker service ps nginx1 lista todas as tarefas de um serviço específico no Docker Swarm, mostrando o estado de cada container, o nó onde está a correr e possíveis erros.

docker service update --replicas=5 --detach=true nginx1

O comando docker service update --replicas=5 --detach=true nginx1 atualiza o serviço nginx1 no Swarm, escalando-o para 5 réplicas e executando a atualização em segundo plano.
